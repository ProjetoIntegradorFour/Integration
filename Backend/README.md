# 📚 Library System Backend

This is the backend service for the **Library System** project, built with **Java Spring Boot**.  
It provides APIs for authentication, user management, and library collection handling.  

---

### Tech Stack

- **Java 24**
- **Spring Boot**
- **REST APIs**
- **External Databases**  
  - Authentication DB (via API)  
  - Collection DB (via API)

---

### Features (WIP)

- User registration & authentication
- Manage book collections
- Borrow/return tracking
- API-based database integration
